# Middle-earth open-world simulator

Personal-use Godot 4 game. Before doing anything:

1. Read `docs/DESIGN.md` (settled decisions; don't change them. Log any concerns in `docs/REVIEW.md`).
2. Read `docs/PLAN.md` §0 (working rules), then find the next unchecked task in `docs/PROGRESS.md`.
3. Follow that task's Steps and run its Verify section. **Never stop to wait for the user.** Judge 📝 REVIEW ITEMs yourself,
   log them, any blockers and fallbacks in `docs/REVIEW.md`, and keep going (see PLAN.md §0.5).

Never write API keys to files. `OPENROUTER_API_KEY` comes from the environment.
